# 🌐 Portfolio — Static Version

A simple, lightweight personal portfolio website built using plain **HTML and CSS**, created as an earlier version before rebuilding with a modern framework.

---

## 📄 Sections

- **Hero** — Introduction
- **About Me** — Background and summary
- **Tech Stack** — Technologies I work with
- **Projects** — Showcase of past work
- **Contact** — Ways to get in touch

---

## 🛠️ Tech Stack

- HTML5
- CSS3

---

## ⚙️ Getting Started

Simply clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/ALI-creator307/portfolio.git
cd portfolio
```

Then open `index.html` directly, or serve it with any static server.
